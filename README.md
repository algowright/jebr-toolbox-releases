## Kurulum

[Releases](../../releases/latest) sayfasından `jebr-toolbox-<sürüm>-windows-x64-setup.exe`
dosyasını indirip çalıştırın. Kurulum yönetici izni istemez; Jebr Toolbox yalnız sizin
kullanıcı hesabınıza kurulur.

## Neler yapar

- **Tek yerden kurulum:** Jebr programlarını tek tıkla kurar ve başlatır.
- **Otomatik güncelleme:** Yeni sürümleri kendisi denetler, indirir ve SHA-256 ile doğrular;
  kendi güncellemelerini de sessizce kurar.
- **Arka planda çalışır:** Pencereyi kapattığınızda saatin yanındaki sistem tepsisinde
  çalışmaya devam eder ve Windows açılışında sessizce başlar. İkisi de Ayarlar'dan kapatılabilir.

## Sistem gereksinimleri

- Windows 10 veya Windows 11, 64 bit
